# Callout

讲解里的「旁白」：五种固定语义，每种都有**字形 + 中英文标签 + 颜色**三重标识，不靠颜色单独区分。

| kind | 字形 | 用在 |
| --- | --- | --- |
| `definition` | ≡ | 第一次引入术语时给出精确定义 |
| `invariant` | ∀ | 算法 / 数据结构始终成立的性质（Raft 的 Log Matching、红黑树的黑高） |
| `insight` | → | 一句话的直觉：把复杂机制压成一个画面 |
| `pitfall` | ! | 常见误解、并发陷阱、退化情况 |
| `note` | i | 版本差异、延伸阅读等补充 |

- 提供：`kind`、可选 `title`（一句话结论）、`children`（1–3 句正文，可含代码与公式）。
- 每屏最多一个；连续两个 Callout 说明正文写得不够。
- 不使用左侧色条卡片样式，统一为浅色底 + 顶部标签行。
