# ArticleCard

文章 / 系列入口卡：编号 + 栏目 + 标题 + 一句话摘要 + 标签与元信息。主页和归档页用它铺成网格（`space-6` 间距，最小宽 300px）。

- 提供：`title`，以及可选的 `no`（文章序号，渲染为 No.017）、`kicker`（栏目，英文大写或短中文）、`summary`（一句话，说清「读完你会明白什么」）、`tags`、`meta`（日期、时长、难度）、`href`。
- 有 `href` 时 hover 上移并落下 `shadow-pop` 硬影；没有链接就不要伪装成可点。
- 摘要写成问题或结论，不写「本文将介绍……」。
- 不放封面图、不放 emoji；视觉识别靠编号与栏目色。
