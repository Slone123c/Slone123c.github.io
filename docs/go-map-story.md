# Go map 滚动叙事设计与验证

主任务：通过原生滚动，看懂一次查找怎样层层缩小范围，以及 map 在集合和索引里的用途。主动作是向下阅读，次动作是跳章、切换命中/未命中、改变索引结果数量。

北极星：带着 alice 进入存储结构，直到亲眼看见 100 被取出来。

原文完整保留在博客文字版，移除作者自己的编辑提示与尚未发布的系列/本地配套链接；iCloud 原稿保持不变。技术基线为原稿中的 Go 1.24.0（64 位）和 Kubernetes v0.31.0。哈希、槽位和查询路径均为原文示意，内存测量保留 Go 1.25.5、macOS arm64 条件，不冒充本次实测。

整体变化：十幕全页背景换色；同一个结构逐层展开、放大；控制字筛出候选，候选 key 被排除后场景移动到下一组；最后从底层结构拉回 Indexer。正文保持静止可读，只有背景与图形做变换。桌面正文与舞台并排，窄屏舞台上置、说明下置。无滚动劫持。系统减少动态效果、脚本失效时，按顺序显示静态帧与正文。

分镜（每幕约 110vh，转场约前 30%，其余留给阅读）：
1. K8s Set 与空 value 的问题；query token 进入画面。
2. directory → table → group → slot 展开。
3. string + 空字段槽位伸展开，对比 bool 同为 24B；展示原文实验条件。
4. 64 位哈希拆为 H1/H2，目录前缀明确属于 H1。
5. directory[2] 指向 table B，group 5 被选中。
6. 控制字扫描 8 个槽位，候选 1/4 被提亮。
7. 完整 key 比较后候选被排除，deleted 不作为终点。
8. 探测推进到 group 6，切换命中与未命中结果。
9. 拉回 client-go 索引，调整结果 N，展示 2+N 次数据查找及额外一次注册检查。
10. 总结每层职责，提供完整原文及源码入口。

本次不做营销页风格探索，不依靠装饰性图片；视觉取自内存网格、控制字与路径本身。未对外部标杆截图做审美评分。

本地验证（1440×900、640×900、390×844）：Node 24 类型检查 0 错误、警告、提示，静态构建成功。十幕正向/反向切换、全页背景还原、中段刷新、命中/未命中切换、索引 N 调整与文字版 9 张 SVG 加载全部通过，无 console/page/HTTP 错误。减少动态效果与关闭 JavaScript 时，十幕均以静态帧直接可读。已查看桌面和窄屏截图并修正连线穿字、SVG 缩放偏移及窄屏正文叠图问题。证据保存在 evidence/go-map/；复验：node scripts/verify-go-map.mjs。尚未做实体手机验证。

官方技术参考：[Go 官方 Swiss Table 说明](https://go.dev/blog/swisstable)，以及文字版中保留的 Go 1.24.0、Kubernetes v0.31.0 源码链接。

## 整页自动播放

增加固定播放器。每幕停留 6 秒，转场 2 秒，完整 1× 约 78 秒；提供暂停/继续、从头播放、0.5×/1×/2×。`?autoplay=1&speed=2` 打开即按 2× 推进；普通网址仍可自主滚动。滚轮、触摸拖动、滚动键和正文交互会停止自动播放，恢复时从当前位置继续；切后台暂停。减少动态效果时保留静态阅读模式，不主动播放。
